# 🚲 Bike Store Data Cleaning Project (MySQL)

This project demonstrates my data cleaning skills using **MySQL** on a Bike Store dataset.

## 📌 Project Overview
The goal of this project was to clean and prepare raw data for analysis and visualization. The dataset contains information related to bike sales, customers, products, and transactions.

## 🛠 Tools Used
- MySQL  
- MySQL Workbench  
- CSV dataset  

## 🔍 What I Did (Data Cleaning Steps)
I performed the following tasks using SQL:

- Removed duplicate records  
- Handled missing values  
- Standardized date formats  
- Fixed inconsistent text values  
- Corrected data types  
- Cleaned categorical columns  
- Prepared final cleaned dataset for analysis  

## 📂 Files in this Repository
- `bike_store_cleaned_data.sql` → SQL script with all cleaning steps  
- `bike_store_cleaned.csv` → Final cleaned dataset

- Power BI dashboard
